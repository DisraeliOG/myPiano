Руководство пользователя программы “Пианино”

1.	Введение
Программа «Пианино» представляет собой настольное приложение, предназначенное для имитации музыкального инструмента пианино на персональном компьютере. Программа позволяет воспроизводить отдельные музыкальные ноты, аккорды и мелодии с помощью графического интерфейса пользователя.
Разработка выполнена на языке C# с использованием технологии WPF. Для воспроизведения звука применяется библиотека NAudio.  
Принятые обозначения
•	ПК — персональный компьютер;
•	Нота — музыкальный звук определённой высоты;
•	Аккорд — одновременное звучание нескольких нот;
•	Клавиша — элемент виртуальной клавиатуры пианино;
•	Октава — последовательность музыкальных нот.
2.	Концепция системы
Программа разработана как обучающее и развлекательное приложение. Пользователь взаимодействует с виртуальной клавиатурой, нажимая клавиши мышью или клавиатурой компьютера.
Основная цель системы — предоставить удобный инструмент для изучения основ музыки и игры на пианино.
2.1	Функционирование системы
После запуска приложения выполняется:
•	инициализация аудиосистемы;
•	загрузка звуковых файлов нот;
•	отображение графического интерфейса;
•	ожидание действий пользователя.
Пользователь может:
•	нажимать клавиши пианино;
•	воспроизводить аккорды;
•	вводить последовательность нот;
•	запускать автоматическое проигрывание мелодии.  
2.2	Основные понятия системы
•	Белые клавиши — основные клавиши нотного ряда.
•	Чёрные клавиши — повышенные/пониженные ноты.
•	Мелодия — последовательность нот, вводимая пользователем.
•	Пауза — временной интервал между нотами.
3.	Работа с программным комплексом
3.1	Установка, запуск и завершение работы
Дополнительные документы для описания объекта не требуются.
Установка программы
1.	Запустить установочный файл приложения.
2.	Выбрать папку установки.
3.	Дождаться завершения установки.
Запуск программы
Для запуска необходимо дважды щёлкнуть по ярлыку программы «Пианино».
Завершение работы
Для завершения работы необходимо закрыть главное окно программы.
3.2	Ввод и воспроизведение мелодии
Условия эксплуатации:
В верхней части окна расположено текстовое поле для ввода мелодии.
Пример записи:
C4 - A4 - A4 - G4
Для воспроизведения необходимо:
1.	Ввести последовательность нот.
2.	Нажать кнопку Play melody.
Допустимые обозначения:
•	- — пауза;
•	| — разделитель;
•	_ — пауза;
•	: — увеличение длительности ноты.  
3.3	Работа с аккордами
В нижней части окна расположены кнопки аккордов:
•	C
•	Dm
•	Em
•	F
•	G
•	Am
•	Bdim
При нажатии кнопки одновременно воспроизводятся несколько нот, соответствующих выбранному аккорду.

5.	Анализ данных

Руководство программиста программы «Пианино»
1.	Общие сведения
Программа «Пианино» представляет собой настольное приложение, реализующее виртуальный музыкальный инструмент с графическим интерфейсом пользователя. Приложение позволяет воспроизводить отдельные ноты, аккорды и пользовательские мелодии.
Программный продукт разработан на языке C# с использованием платформы .NET и технологии WPF. Для работы со звуком используется библиотека NAudio.  
Руководство предназначено для программистов, выполняющих сопровождение, модификацию и расширение функциональности приложения.
2.	Назначение программы
Программа предназначена для:
•	воспроизведения музыкальных нот;
•	воспроизведения аккордов;
•	проигрывания мелодий;
•	демонстрации принципов работы аудиоприложений;
•	дальнейшего развития и модификации проекта.
3.	Средства разработки
Для сборки и сопровождения проекта используются:
•	Microsoft Visual Studio;
•	.NET;
•	C#;
•	WPF;
•	NAudio.  
4.	Структура проекта
Проект содержит следующие основные файлы:
•	App.xaml — ресурсы приложения и точка запуска;
•	MainWindow.xaml — описание графического интерфейса;
•	MainWindow.xaml.cs — обработка событий интерфейса;
•	AudioManager.cs — управление аудиосистемой;
•	CachedSound.cs — загрузка и хранение звуков в памяти;
•	папка Audio/ — аудиофайлы нот.  
5.	Архитектура программы
Программа состоит из трёх основных уровней:
5.1	Уровень представления
Отвечает за отображение интерфейса и взаимодействие с пользователем.
Основной объект:
•	MainWindow
5.2	Логический уровень
Обрабатывает действия пользователя:
•	воспроизведение нот;
•	запуск аккордов;
•	проигрывание мелодии;
•	обработка клавиатуры.
5.3	Аудиоуровень
Отвечает за:
•	загрузку звуков;
•	микширование нескольких потоков;
•	воспроизведение звука.
Основной объект:
•	AudioManager
6.	Описание классов
6.1	Класс MainWindow
Назначение
Главное окно приложения.
Поля
•	_pressedKeys — множество нажатых клавиш клавиатуры.
Основные методы
PlayNote(string note)
Входные параметры:
note — название ноты.
Назначение:
Передаёт команду на воспроизведение ноты.
Результат:
Проигрывание выбранного звука.
Note_Click(object sender, RoutedEventArgs e)
Назначение:
Обработка нажатия кнопки клавиши пианино.
Chord_Click(object sender, RoutedEventArgs e)
Назначение:
Воспроизведение выбранного аккорда.
PlayMelody_Click(object sender, RoutedEventArgs e)
Назначение:
Проигрывание мелодии, введённой пользователем.
Window_KeyDown(...)
Назначение:
Обработка нажатия клавиши клавиатуры ПК.
Window_KeyUp(...)
Назначение:
Обработка отпускания клавиши.
6.2	Класс AudioManager
Назначение
Управление аудиосистемой приложения.
Поля
•	_outputDevice — устройство вывода звука;
•	_mixer — микшер звуковых потоков;
•	_soundCache — кэш загруженных нот;
•	FilePaths — список файлов нот.
Методы
Initialize()
Инициализирует аудиоустройство и загружает звуки.
Play(string note)
Воспроизводит указанную ноту.
Dispose()
Освобождает ресурсы аудиосистемы.
6.3	Класс CachedSound
Назначение
Хранение аудиоданных ноты в оперативной памяти.
Поля
•	AudioData — массив звуковых данных;
•	WaveFormat — формат аудио.
Конструктор
CachedSound(string audioFileName)
Загружает файл и преобразует его к стандартному формату.  
6.4	Класс CachedSoundSampleProvider
Назначение
Передача звуковых данных в аудиосистему.
Основной метод
Read(float[] buffer, int offset, int count)
Копирует звуковые данные в выходной буфер воспроизведения.

Руководство системного администратора программы «Пианино»

Программа «Пианино» представляет собой настольное приложение, предназначенное для воспроизведения музыкальных нот, аккордов и мелодий на персональном компьютере.
Программный продукт разработан на языке C# с использованием платформы .NET и технологии WPF. Для работы со звуком используется библиотека NAudio.  
Программа предназначена для установки на локальные рабочие станции пользователей и не требует серверной инфраструктуры.
