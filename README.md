# 🎹 Piano

Виртуальное пианино, разработанное на **C#**, **WPF** и **NAudio**. Приложение позволяет воспроизводить отдельные ноты, аккорды и пользовательские мелодии через графический интерфейс.

## Возможности

* Воспроизведение отдельных нот
* Поддержка двух октав
* Воспроизведение аккордов
* Ввод и проигрывание пользовательских мелодий
* Управление с клавиатуры ПК
* Визуальная подсветка нажатых клавиш
* Одновременное воспроизведение нескольких нот

## Используемые технологии

* C#
* .NET
* WPF
* NAudio

## Архитектура

### Уровень представления

Отвечает за отображение интерфейса и взаимодействие с пользователем.

Основной класс:

* `MainWindow`

### Логический уровень

Обрабатывает действия пользователя:

* воспроизведение нот;
* воспроизведение аккордов;
* проигрывание мелодий;
* обработку клавиатуры.

### Аудиоуровень

Отвечает за:

* загрузку звуков;
* микширование аудиопотоков;
* воспроизведение звука.

Основной класс:

* `AudioManager`

## Управление

### Белые клавиши

| Клавиша | Нота |
| ------- | ---- |
| Z       | C4   |
| X       | D4   |
| C       | E4   |
| V       | F4   |
| B       | G4   |
| N       | A4   |
| M       | B4   |
| Q       | C5   |
| W       | D5   |
| E       | E5   |
| R       | F5   |
| T       | G5   |
| Y       | A5   |
| U       | B5   |

Для чёрных клавиш используются дополнительные клавиши клавиатуры.

## Ввод мелодии

В поле ввода можно указать последовательность нот.

Пример:

```text
C4 - A4 - A4 - G4
```

Поддерживаемые обозначения:

| Символ | Назначение                   |
| ------ | ---------------------------- |
| -      | пауза                        |
| _      | пауза                        |
| |      | разделитель                  |
| :      | увеличение длительности ноты |

После ввода нажмите кнопку **Play Melody**.

* F
* G
* Am

## Основные классы

### MainWindow

Главное окно приложения.

Основные методы:

```csharp
PlayNote(string note)
Note_Click(object sender, RoutedEventArgs e)
Chord_Click(object sender, RoutedEventArgs e)
PlayMelody_Click(object sender, RoutedEventArgs e)
Window_KeyDown(...)
Window_KeyUp(...)
```

### AudioManager

Управление аудиосистемой.

Основные методы:

```csharp
Initialize()
Play(string note)
Dispose()
```

### CachedSound

Загрузка и хранение аудиоданных в памяти.

### CachedSoundSampleProvider

Передача звуковых данных в аудиосистему.

## Алгоритм работы

1. Запуск приложения.
2. Создание окна MainWindow.
3. Инициализация аудиосистемы.
4. Загрузка нот из каталога Audio.
5. Ожидание действий пользователя.
6. Обработка нажатий клавиш.
7. Воспроизведение звука.
8. Освобождение ресурсов при закрытии.
